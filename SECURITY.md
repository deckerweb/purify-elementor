# Security / Sicherheit

Report security issues privately through the host repository: Security → Advisories → Report a vulnerability. Include Purify, WordPress, Elementor and embedded Library versions. Do not publish vulnerabilities or credentials in public Issues. If private reporting is unavailable, request a confidential reporting channel without disclosing details.

Sicherheitsprobleme privat im Host-Repository melden: Security → Advisories → Report a vulnerability. Versionen von Purify, WordPress, Elementor und eingebetteter Library angeben. Keine Schwachstellen oder Zugangsdaten in öffentlichen Issues veröffentlichen. Wenn private Meldungen nicht verfügbar sind, zunächst ohne Details einen vertraulichen Meldeweg anfragen.
